## Las 8 etapas de DevOps

**Importancia de seguir las etapas de DevOps** Los proyectos deben adaptarse a las etapas de DevOps, no al revés. Cambiar el orden o modificar las etapas según conveniencia rompe con la metodología y su propósito.

**1. Planeación** Consiste en definir qué incluirá y qué no incluirá el proyecto. Es clave para establecer los límites y objetivos claros desde el inicio.

**2. Programación** Etapa más familiar y disfrutada por muchos. Es solo una de las ocho y no debe considerarse la única o principal.

**3. Compilación** Va más allá de presionar F5. En DevOps, debe automatizarse para integrarse de forma continua en el flujo de trabajo.

**4. Pruebas** Se crean pruebas unitarias, de integración y extremo a extremo (E2E) para validar que el código funciona correctamente con el resto del sistema.

**5. Liberación** Una vez probado, el software se libera hacia la solución general, integrándose con los demás componentes.

**6. Despliegue** Consiste en mover el software a distintos ambientes como desarrollo, pruebas o producción. Esta etapa cubre todos los entornos posibles.

**7. Operación** Se pone en marcha la solución y se verifica que las funcionalidades estén activas y operativas como se esperaba.

**8. Monitoreo** Clave para la observabilidad. Permite evaluar el comportamiento del sistema, detectar mejoras y mantener una mejora continua, como en servicios tipo Uber o Netflix.

**Importancia de la observabilidad y mejora continua** Sin monitoreo, no sería posible la evolución constante del software. Esta etapa alimenta el ciclo de retroalimentación para nuevas versiones.

**Preparación previa recomendada para DevOps** Antes de abordar DevOps, se recomienda haber cursado materias como Git y GitHub, pruebas de APIs, fundamentos de Docker, GitHub Actions, Terraform y plataformas en la nube como AWS, GCP o Azure.

**Conclusión** Una vez cubiertos estos fundamentos, se está listo para implementar DevOps de manera eficaz y fluida en proyectos reales.

---
DevOps es una metodología que se compone de 8 etapas fundamentales para proyectos de software:

1. **Planeación**: Definir objetivos y limitaciones del proyecto.
2. **Programación**: Desarrollo del código.
3. **Compilación**: Automatizar el proceso de compilación del código.
4. **Pruebas**: Implementar pruebas unitarias e integradas.
5. **Liberación**: Preparar el código para ser liberado.
6. **Despliegue**: Implementar en diferentes entornos (desarrollo, pruebas, producción).
7. **Operación**: Mantener el funcionamiento del sistema.
8. **Monitoreo**: Observabilidad del sistema para mejorar continuamente.

Estas etapas aseguran un proceso de desarrollo estructurado y eficiente.
