Ayuda a verificar la instalacion
```shell
flutter doctor
```

Crear un nuevo poryecto en flutter
```shell
flutter create
```

Despliega el proyecto
```shell
flutter run
```

Descargar dependencias:

``` shell
flutter pub get
```
  
Actualizar todas las librerías a las más recientes:

```shell
flutter pub upgrade
```

Forzar actualización mayor (breaking changes)

  flutter pub upgrade --major-versions

  Comandos adicionales útiles:

  # Limpiar caché y reinstalar
  flutter clean && flutter pub get

  # Actualizar Flutter SDK
  flutter upgrade
